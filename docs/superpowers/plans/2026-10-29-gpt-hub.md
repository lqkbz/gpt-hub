# gpt-hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AstrBot 插件 `astrbot_plugin_gpt_hub`：按会话+按人的模式/权限/限流，群可设模型与推理强度，提供 /draw、/research、/say、/voice，并附 VPS 部署文件。

**Architecture:** `core/` 纯 Python 逻辑（不 import astrbot，可单测）；`main.py` 薄胶水注册 AstrBot 命令与钩子。聊天路由靠 `event.set_extra("selected_provider"/"selected_model")`；effort 通过 effort→provider id 映射实现。研究与订阅生图通过 `codex exec` 子进程。

**Tech Stack:** Python 3.12、AstrBot 4.29.x 插件 API、sqlite3、asyncio、aiohttp（AstrBot 自带）、pytest + pytest-asyncio、Codex CLI 0.165+、Docker Compose、NapCat。

Spec：`docs/superpowers/specs/2026-10-29-gpt-hub-design.md`

## Global Constraints

- core/ 内禁止 import astrbot；外部依赖（子进程、HTTP、时间）可注入以便测试。
- 用户可见文案中文、一行为主；异常不外泄栈。
- 功能名固定：`draw`、`research`、`voice`。effort 取值：`none|minimal|low|medium|high|xhigh`（实际可用值由 `effort_providers` 键决定）。
- 时区默认 `Asia/Shanghai`，日计数按该时区日期。
- codex 调用默认参数：`exec --skip-git-repo-check --ephemeral`；研究用 `-s read-only`，生图用 `-s workspace-write`；均 `-C <任务目录>`、`-o <last_message 文件>`。
- 测试命令：`python -m pytest -q`（在仓库根目录）。

### Task 3: ratelimit.py + policy.py

**Files:**
- Create: `plugins/astrbot_plugin_gpt_hub/core/ratelimit.py`、`plugins/astrbot_plugin_gpt_hub/core/policy.py`
- Test: `tests/test_ratelimit.py`、`tests/test_policy.py`

**Interfaces:**
- Consumes: `HubConfig`、`FEATURES`（Task 1）；`Store`、`GroupPolicy`（Task 2）
- Produces:
  - `class SlidingWindow(limit: int, window_s: float = 60.0)`：`hit(key: str, now: float) -> bool`（允许则记录并返回 True）
  - `@dataclass(frozen=True) MsgCtx(sender_id: str, group_id: str | None)`（None=私聊）
  - `@dataclass(frozen=True) ChatRoute(allowed: bool, provider_id: str|None = None, model: str|None = None, reason: str = "")`
  - `@dataclass(frozen=True) FeatureCheck(allowed: bool, reason: str = "")`
  - `class Policy(cfg: HubConfig, store: Store, clock: Callable[[], float] = time.time)`：
    - `is_owner(sender_id) -> bool`
    - `today() -> str`（cfg.timezone 下 `YYYY-MM-DD`）
    - `effective_chat(group_id: str|None) -> tuple[str|None, str]`：返回 (model 或 None, effort)，供 `/mode` 展示与路由共用
    - `route_chat(ctx) -> ChatRoute`（放行时消耗聊天配额；owner 不消耗）
    - `check_feature(ctx, feature) -> FeatureCheck`（不消耗）
    - `consume_feature(ctx, feature) -> None`
- 计数 key：聊天群日计数 `chat:{group}`；功能 `feat:{feature}:{group}:{user}`。

**route_chat 规则：**
1. owner → allowed，provider=`effort_providers.get(owner_effort)`，model=`owner_model or None`。
2. 私聊非 owner：`private_chat_enabled` 假 → `reason="private_disabled"`；否则用群默认 model/effort，限流 key `p:{user}`。
3. 群：`chat_enabled` 假 → `reason="chat_off"`；每分钟窗口 key `{group}:{user}` 超限 → `reason="user_rate"`；群日计数 > `chat_group_per_day` → `reason="group_daily"`。
4. provider 为 `effort_providers.get(effort)`，无映射则 None（用会话默认 provider）。

**check_feature 规则：** owner 放行；私聊非 owner → `"该功能仅 owner 可用"`；群未开放 → `"本群未开放 {feature}"`；当日计数 ≥ 配额 → `"今日 {feature} 次数已用完（{quota}）"`。

- Produces（procs.py）：
  - `@dataclass ProcResult(returncode: int, stdout: str, stderr: str, timed_out: bool)`
  - `async run_process(argv: list[str], *, cwd: str|None = None, timeout: float, env: dict|None = None) -> ProcResult`：超时杀进程树（POSIX `start_new_session=True` + `os.killpg`；Windows `proc.kill()`）；被取消时同样杀进程后重抛。

  - `class BackendError(Exception)`
  - `@dataclass ImageResult(path: str|None = None, url: str|None = None, backend: str = "")`
  - `class HttpClient(Protocol)`：`async post_json(url: str, headers: dict, payload: dict, timeout: float) -> dict`
  - `class AiohttpClient`：实现 HttpClient；非 2xx 抛 `BackendError(f"HTTP {status}: {text[:200]}")`
  - `class OpenAIImagesBackend(conf: DrawBackendConf, http: HttpClient, timeout: float)`：POST `{base_url.rstrip('/')}/images/generations`，payload `{model, prompt, size, n: 1}`，头 `Authorization: Bearer`；`data[0].b64_json` → 写 `out_dir/{name}.png` 返回 path；否则 `data[0].url` → url；都无 → BackendError
  - `class CodexCliImageBackend(name: str, codex_bin: str, codex_home: Path, timeout: float, runner: Runner = run_process, clock = time.time)`：argv `[codex_bin, "exec", "--skip-git-repo-check", "--ephemeral", "-s", "workspace-write", "--enable", "image_generation", "-C", out_dir, "-o", out_dir/"last.txt", PROMPT]`；完成后在 out_dir 与 `codex_home/"generated_images"` 递归找 mtime ≥ 开始时间-1 的最新 png/jpg/jpeg/webp，不在 out_dir 则复制进来；超时/返回码非 0/无图 → BackendError
  - 统一接口：`async generate(prompt: str, out_dir: Path) -> ImageResult`，属性 `name: str`
  - `class DrawService(backends: list, work_root: Path)`：`async draw(prompt) -> ImageResult`，每次新建 `work_root/<uuid>`，依次尝试，全失败抛 `BackendError("全部生图后端失败：name: err; ...")`；无后端 → `BackendError("未配置生图后端")`
  - `build_backends(cfg: HubConfig, http: HttpClient, codex_home: Path, runner: Runner = run_process) -> list`

### Task 6: research.py

**Files:**
- Create: `plugins/astrbot_plugin_gpt_hub/core/research.py`
- Test: `tests/test_research.py`

**Interfaces:**
- Consumes: `HubConfig`、`Store`、`ResearchJob`、`run_process`/`Runner`/`ProcResult`/`classify_codex_error`
- Produces:
  - `RESEARCH_PROMPT: str`（含 `{topic}`；要求：拆子问题→多轮联网搜索阅读→交叉核对→中文 Markdown 报告：摘要/正文分节/结论/引用链接列表；只输出报告本身）

    - `async start()`：`store.mark_unfinished_interrupted` 并逐个通知 `"研究 #{id} 因重启中断：{topic}"`；启动 `research_concurrency` 个 worker
    - `async stop()`：取消 worker 与运行中任务
    - `submit(umo, requester, topic) -> ResearchJob`：入库 queued 并入队
    - `cancel(job_id: int, requester: str, is_owner: bool) -> str`：不存在 → `"任务不存在"`；非本人且非 owner → `"只能取消自己的任务"`；queued → cancelled；running → 取消 task 并标记 cancelled；其他 → `"任务已结束（{status}）"`
    - `status_text(umo: str, job_id: int | None) -> str`：指定 id 显示该任务；否则列出本会话最近 5 个
    - `build_argv(job_dir: Path, topic: str) -> list[str]`：`[codex_bin, "exec", "--skip-git-repo-check", "--ephemeral", "-s", "read-only", (-m model 若非空), "-c", f'model_reasoning_effort="{research_effort}"', *research_extra_args, "-C", job_dir, "-o", job_dir/"report.md", prompt]`
- 任务执行：running → 运行 → 超时：failed `"超时（{n}s）"`；返回码非 0：failed `classify_codex_error`；report.md 不存在或为空：failed `"未生成报告"`；成功：done，通知 `f"研究 #{id} 完成：{topic}\n\n{摘要}"` + report 路径（摘要=报告前 `research_summary_chars` 字，超出加 `…`）。失败也通知 `f"研究 #{id} 失败：{error}"`。worker 取到已 cancelled 的任务直接跳过。
